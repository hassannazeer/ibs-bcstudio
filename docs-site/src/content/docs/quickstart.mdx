<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { BCClient } from '@ilmora/bc-client';

    const client = new BCClient({
      tenantId:     process.env.BC_TENANT_ID,
      clientId:     process.env.BC_CLIENT_ID,
      clientSecret: process.env.BC_CLIENT_SECRET,
      environment:  'production',
      companyId:    process.env.BC_COMPANY_ID,
    });

    const customers = await client.getAll(
      'api/v2.0/companies({companyId})/customers',
      {
        odataOptions: {
          top:    50,
          select: ['id', 'number', 'displayName'],
          filter: [{ field: 'blocked', op: 'eq', value: false }],
        },
      }
    );

    const record = await client.getOne(
      'api/v2.0/companies({companyId})/customers',
      customers[0].id
    );

    await client.patch(
      'api/v2.0/companies({companyId})/customers',
      customers[0].id,
      { displayName: 'Updated name' },
      record.etag
    );
    ```

    `patch()` and `delete()` require the ETag. Pass `*` only if you deliberately skip the concurrency check. `getAll()` follows `@odata.nextLink` until the set is complete.

    To discover a company ID by name:

    ```ts
    const id = await client.resolveCompanyId('CRONUS International Ltd.');
    const scoped = client.withCompany(id);
    ```
  </TabItem>
  <TabItem label="Python">
    The project name is `ibs-bcstudio` (coming soon on PyPI). The import name is `bcstudio`.

    ```python
    import os
    from bcstudio import BCClient
    from bcstudio.client import BCConnectionConfig

    client = BCClient(BCConnectionConfig(
        tenant_id=os.environ["BC_TENANT_ID"],
        client_id=os.environ["BC_CLIENT_ID"],
        client_secret=os.environ["BC_CLIENT_SECRET"],
        environment="production",
        company_id=os.environ["BC_COMPANY_ID"],
    ))

    customers = client.get_all(
        "api/v2.0/companies({companyId})/customers",
        {
            "top": 50,
            "select": ["id", "number", "displayName"],
            "filter": "blocked eq false",
        },
    )

    record = client.get_one(
        "api/v2.0/companies({companyId})/customers",
        customers[0]["id"],
    )

    client.patch(
        "api/v2.0/companies({companyId})/customers",
        customers[0]["id"],
        {"displayName": "Updated name"},
        record.etag,
    )
    ```

    `patch()` and `delete()` require the ETag. `get_all()` follows `@odata.nextLink` until the set is complete.
