## Quickstart

TypeScript, matching the `@ilmora/bc-client` API. `patch()` and `delete()` require the ETag (or `*` if you deliberately skip the concurrency check). `getAll()` follows `@odata.nextLink` until the set is complete.

```ts
import { BCClient } from '@ilmora/bc-client';

const client = new BCClient({
  tenantId:     process.env.BC_TENANT_ID!,
  clientId:     process.env.BC_CLIENT_ID!,
  clientSecret: process.env.BC_CLIENT_SECRET!,
  environment:  'production',
  companyId:    process.env.BC_COMPANY_ID,
});

const customers = await client.getAll(
  'api/v2.0/companies({companyId})/customers',
  {
    odataOptions: {
      top:    50,
      select: ['id', 'number', 'displayName'],
      filter: [{ field: 'blocked', op: 'eq', value: false }],
    },
  }
);

const record = await client.getOne(
  'api/v2.0/companies({companyId})/customers',
  customers[0].id
);

await client.patch(
  'api/v2.0/companies({companyId})/customers',
  customers[0].id,
  { displayName: 'Updated name' },
  record.etag
);
```

## What it handles

<CardGrid>
  <Card title="Filters" icon="magnifier">
    The SDK can detect a `$filter` that was ignored on some custom API pages, and apply the filter in memory.
  </Card>
  <Card title="ETag" icon="approve-check">
    `patch()` and `delete()` require the ETag. Learn documents the `If-Match` header; a missing header fails the call.
  </Card>
  <Card title="Retry" icon="reload">
    The client retries on HTTP 429 and, when Business Central sends `Retry-After`, waits for that value.
  </Card>
  <Card title="Pagination" icon="list-format">
    `getAll()` follows the `@odata.nextLink` until the set is complete. Page size is not something you can assume.
  </Card>
  <Card title="Bound actions" icon="seti:todo">
    Standard `shipAndInvoice` and `receiveAndInvoice` return 204. `SetResultCode(Created)` returns 201 with a Location header and no body. `callAction()` reports the status.
  </Card>
  <Card title="Company ID" icon="setting">
    Set `companyId` once, use the `{companyId}` placeholder in paths, or call `withCompany()` / `resolveCompanyId()`.
  </Card>
</CardGrid>
